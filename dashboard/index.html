What the reviewer can trust

Workflow

Two agents, one gate, a person at the end of every path

A deterministic orchestrator, run_pipeline.py, runs the steps in order: code controls the flow, Claude only does the judgment inside each stage. If Notion is unreachable, the report is held and Slack is alerted instead of anything being dropped. Reports are independent, so they run one at a time for rate limits and an ordered decision trail; the pattern finder waits until every report is classified.
